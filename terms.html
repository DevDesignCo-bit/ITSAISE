Villkor & Betingelser

Dessa villkor utgör de särskilda villkoren för avtalet mellan dig, nedan kallad ”Användaren”, och NEXT MOVE DIGITAL LTD, som driver tjänsten ITSAI.

1. Syfte

ITSAI är en mobil tjänst med en plattform för att skapa AI-drivna PowerPoint-presentationer på några sekunder. Tjänsten erbjuder en prenumeration som aktiveras när du bekräftar din beställning på ITSAI:s mobilwebbplats, itsai-online.com.

2. Villkor för användning

Detta erbjudande gäller användare i Sverige. Du måste ha nödvändigt tillstånd att använda tjänsten via ditt mobilabonnemang. Genom att fortsätta bekräftar du att du är minst 18 år.

3. Beskrivning av tjänsten

3.a. Prenumeration

Prenumerationen ger tillgång till ITSAI:s plattform för att skapa AI-drivna PowerPoint-presentationer. Priset är 200 SEK per månad inklusive moms. Eventuella avgifter för mobil internetanslutning tillkommer enligt ditt avtal med mobiloperatören.

Du beställer genom att följa instruktionerna på ITSAI:s mobilwebbplats och bekräfta prenumerationen. När beställningen har godkänts får du tillgång till plattformen.

Prenumerationen förnyas automatiskt tills du avslutar den. Du kan avsluta när som helst via länken för att avsluta prenumerationen i din personliga meny. För det svenska erbjudandet kan du även skicka STOP ITSAI+ till 72300. ITSAI förbehåller sig rätten att avsluta prenumerationen.

4. Hjälp och support

Kontakta oss via support@itsai-online.com om du behöver hjälp med tjänsten, prenumerationen eller betalningen.

5. Betalning

Priset visas på de sidor där tjänsten kan beställas. För detta erbjudande debiteras 200 SEK per månad inklusive moms. Kostnaden hanteras via din mobiloperatör.

Om du har ett fakturerat abonnemang läggs kostnaden till på din mobilräkning. Om du använder kontantkort måste saldot vara tillräckligt för att täcka prenumerationen.

Avgifter kan variera beroende på mobiloperatör. Det exakta priset och tjänstens villkor visas före beställningen. Användning av mobilt internet kan medföra ytterligare kostnader enligt ditt avtal med operatören. ITSAI ansvarar inte för dessa anslutningskostnader.

6. Tillgång till tjänsten

Det svenska erbjudandet riktar sig till användare som är minst 18 år. Innehavaren av mobilabonnemanget ansvarar för användningen av abonnemanget.

Du ansvarar för att ha den utrustning, programvara och internetanslutning som behövs. ITSAI kan avbryta tjänsten för reparationer, rättelser och underhåll. Vissa tjänster eller produkter kan ändras tillfälligt eller permanent.

7. Användarens ansvar

ITSAI ansvarar inte för förlust eller skada som uppstår genom felaktig användning av tjänsten eller genom omständigheter utanför ITSAI:s kontroll, i den utsträckning som tillämplig lag tillåter.

Du får inte missbruka tjänsten eller göra intrång i tredje parts rättigheter, inklusive varumärken, patent, upphovsrätt och andra immateriella rättigheter. Tjänsten får inte användas för kommersiella ändamål eller andra ändamål som inte omfattas av dessa villkor.

8. ITSAI:s ansvar

ITSAI ansvarar inte för den tekniska tillgängligheten eller innehållet på webbplatser som drivs av tredje part och som nås via länkar från tjänsten. Sådana länkar innebär inte att ITSAI godkänner eller rekommenderar tredje parts produkter, tjänster, information eller annat material.

ITSAI kontrollerar inte kvaliteten, lagligheten, tillförlitligheten eller användbarheten hos länkade externa webbplatser. ITSAI ansvarar inte för bristande leverans som beror på omständigheter som inte kan hänföras till ITSAI, exempelvis tekniska problem utanför plattformens kontroll, i den utsträckning som tillämplig lag tillåter.

ITSAI förbehåller sig rätten att ta bort, lägga till eller ändra innehåll, tjänster och funktioner på plattformen.
